# Word of God App ✝️

A modern React-powered church ministry website designed to share the Gospel, provide daily verses, display events, accept prayer requests, and glorify God with a clean and responsive UI.

---

## ✨ Features

- 🕊️ **Homepage** with hero banner  
- 📖 **Daily Bible Verse** section  
- 🎵 **Worship & Praise** content (optional)  
- 🗓️ **Church Events**  
- 🙏 **Prayer Request Form**  
- 📸 **Gallery Section**  
- 📍 **Church Location & Contact Information**  
- ⚡ Built using **React.js** (Create React App)
